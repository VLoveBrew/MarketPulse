# MarketPulse Intelligence Engine

A clickable prototype for a market and competitor intelligence product.

The app demonstrates a monetization funnel:

- Free market snapshot for lead capture
- Paid deep-dive analysis modules
- Premium MCP access for AI-native teams
- Human consultant upgrades for strategic work

## Local preview

```bash
pnpm install
pnpm run dev
```

## Build

```bash
pnpm run build
```
